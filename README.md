# SCALAE website

Static site (`index.html`, `styles.css`, `main.js`, `assets/`), hosted on GitHub Pages. No build step.

The intro film and glass loop are Remotion compositions in `film/` (run `npm i`, then
`python music.py`, then `npx remotion render src/index.tsx Film ../assets/video/scalae-intro.mp4 --gl=angle`).
